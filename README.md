# Hi, I'm Golopmoui3 👋

I ship working software: 3D games in the browser, Windows/Linux tooling, and upstream fixes to open-source projects I actually use.

## 🔨 My tools & games

| Project | What it does |
|---|---|
| [neon-wasteland](https://github.com/Golopmoui3/neon-wasteland) | Open-world 3D survival wave shooter in the browser (Three.js, procedural world, bosses, shop, quests). **Zero assets** — every texture, mesh and sound is generated by code. [Play it](https://golopmoui3.github.io/neon-wasteland/) |
| [wsl-doctor](https://github.com/Golopmoui3/wsl-doctor) | One command to diagnose and heal the classic WSL2 networking wounds: self-regenerating `resolv.conf`, systemd-resolved stub DNS, docker that never starts |
| [gh-device-login](https://github.com/Golopmoui3/gh-device-login) | GitHub CLI auth on headless machines via the OAuth device flow — bash + curl only, token never touches disk |
| [repo-sandbox](https://github.com/Golopmoui3/repo-sandbox) | Run an untrusted repo's test suite in a throwaway container and get a verdict: does your patch turn the upstream suite green? |

## 🛠 How I work

- Everything runs through isolation first: my tools were built because I hit the problems myself, then generalized
- Test the fix against upstream HEAD, not just against hope — [repo-sandbox](https://github.com/Golopmoui3/repo-sandbox) exists for exactly this
- DCO-signed commits, tests included, no drive-by README typos
